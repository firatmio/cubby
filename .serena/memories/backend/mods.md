# backend/mods (M8) — Modrinth mod/eklenti mağazası

- `modrinth.rs` — API v2 (anahtarsız, 300 istek/dk, `consts::USER_AGENT`). `loaders_for`: Fabric → fabric; Paper → paper|bukkit|spigot|purpur (eklentiler Modrinth'te `project_type: mod` olarak geliyor, ayıran loader kategorisi). `facets()` = loader OR grubu + `versions:<mc>` + `server_side:required|optional` (+ kategori). Uç noktalar: search, project, projects?ids, versions?ids, version/{id}, project/{id}/version?loaders&game_versions, POST version_files (sha1 → sürüm), POST version_files/update (güncelleme). reqwest 0.13'te `.query()` için `query` özelliği açık.
- `mods/mod.rs` — `primary_jar`, `pick_version` (release>beta>alpha, sonra en yeni), `sanitize_filename`, `Source` trait + `resolve` (BFS, required bağımlılıklar, kurulu/görülen atlanır, incompatible→conflicts, bulunamayan→missing; kök bulunamazsa hata), kayıt `instance/.mcsm/mods.json` `[ModRecord{file, sha1, projectId, versionId, dependency}]` (M7b mod eşitlemesi bunu kullanacak), `scan` (jar + sha1), `reconcile`, `download_into` (önce `.mcsm/downloads`'a sha512 doğrulamalı, sonra içeri; replace → eskisi trash; aynı sha1 varsa indirmez).
- `mods_cmds.rs` — `mods_search/project/install/installed/remove/update/update_all`; `OPS` global tokio Mutex (tek işlem); event `mods://progress {id,title,downloaded,total}`; `ModIcons` (projectId→icon_url) + `media://modicon/<id>` (lib.rs'de async dal; yalnız cdn.modrinth.com, 1 MB, sihirli bayttan MIME, `app_data/cache/modicons`).
- Canlı testler: `live_modrinth_search`, `live_install_with_dependency` (Chunky → Fabric API bağımlılığı).
