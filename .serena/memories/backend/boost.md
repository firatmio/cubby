# Hızlandırıcı (boost.rs)

- `meta/boost.json` (`Boost`): enabled, verified, suspect, fabric (saf dünyaya arka planda kurulan Fabric sürümü), unavailable (proje kimlikleri), checked_at, last_error, applied (son açılışta uygulandı mı). Yeni dünyalar `commands::create_instance` → `boost::init_new(meta, modpack yoksa true)`; mevcut dünyalar kapalı.
- `CANDIDATES`: Lithium gvQqBUqZ, C2ME VSNURh3q (yalnız alpha sürümleri var; `pick_version` alpha'yı en son seçer), ScalableLux Ps1zyz6x, FerriteCore uXXizFIs, ModernFix nmDcB62a. Modrinth'te o sürüm/yükleyici için yoksa ya da `client_side == required` ise atlanır.
- `mode(loader)`: Paper → JavaOnly, Vanilla → VanillaFabric, diğerleri Mods. `runtime(loader, &b)`: saf + açık + fabric kurulu → Fabric; Chunky de bu yolla (`server_loader`, `install_server_mod`) saf dünyaya kurulabilir.
- Açılış: `commands::start_server` → `servers.start_with(app, id, |log| ...)` (durum hemen Starting, `StartLog::line` konsola sistem satırı yazar) → `boost::prepare` (OPS kilidi) → `launch_args`. Hata açılışı durdurmaz. Java bayrakları `boost::jvm_flags(max_mb, java.major)` her dünyada (`-XX:+IgnoreUnrecognizedVMOptions` en başta; Java 27'de ParallelRefProcEnabled ve InitiatingHeapOccupancyPercent eklenmez).
- Saf dünyaya Fabric: `Loaders::install_fabric_over_vanilla` (server.jar `.fabric/server/<mc>-server.jar` önbelleğine kopyalanır, `fabric-server-launch.jar` iner). `inst.loader` Vanilla kalır → arayüz, Keşfet sekmeleri, arkadaş eşitlemesi saf davranır.
- `ModRecord.managed`: Hızlandırıcı'nın modları (ve bağımlılıkları); `need = ClientNeed::None` (installed_view üzerine yazmaz), güncellemede korunur. Kapatınca `meta/boost-off/`'a (dosya + mods.json) taşınır (`stash`/`unstash`), silinmez.
- C2ME: `config/c2me.toml` C2ME'nin ilk açılışında oluşur (sürüm alanı uymazsa C2ME sıfırlar, biz yazmayız); `globalExecutorParallelism` satırı `c2me_threads(cores)` = çekirdek/2, 2..8 ile değiştirilir.
- Durum: `running` → verified; doğrulanmadan `crashed` → suspect (Hero hapı "kapatıp dene"). Olay `boost://status {id, boost: BoostView}`; komutlar `boost_status`, `boost_set`.
- Ölçüm: `cargo test --release live_boost_bench -- --ignored --nocapture` (CUBBY_BENCH_MC/RADIUS/JAVA). 2026-10-18, MC 26.3, Java 27, 20 çekirdek (C2ME 8 iş parçacığı): Chunky 500 blok 28,8→17,2 sn (1,67x), 1000 blok 80,2→53,7 sn (1,49x), açılış ~16→12 sn. C2ME'nin `config/c2me.toml`'da üst seviyede `globalExecutorParallelism = "default"` satırı var (doğrulandı).
- Arayüz: `screens/world/BoosterCard.tsx` (PerformanceSection içinde), Keşfet › Kurulu'da "Hızlandırıcı" rozeti + şimşek düğmesi (Performans'ı açar).
