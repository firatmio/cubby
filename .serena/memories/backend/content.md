# backend/content (M10b: kaynak paketleri, shader'lar, veri paketleri)

- `modrinth::ContentKind { Mod, ResourcePack, Shader, DataPack }` (serde camelCase). `content_facets` (rp: project_type:resourcepack; shader: project_type:shader + categories:iris|optifine; datapack: project_type:datapack; hepsine versions:mc + kategori). `kind.loaders(world)` sürüm sorgusu yükleyicileri (rp ["minecraft"], shader ["iris","optifine"], dp ["datapack"]), `kind.ext()` jar/zip. `project_versions_for`, `latest_for_loaders`, `search_content`.
- `mods`: `primary_file(v, ext)`, `pick_version_ext`, `download_into_ext`, `sanitize_filename_ext`; paket adları `safe_pack_name` ile güvenli karaktere çevrilir (boşluk vb. → `_`), reddedilmez.
- `content.rs` (saf): dünya başına `content.json` (`Record`: resourcepacks/shaders/datapacks [Item: file, sha1, project_id, version_id, title, url], client_mods [ModRecord, shader ekstraları], active_shader, forced_pack); `enable_pack/disable_pack` (options.txt `resourcePacks:[...]`), `set_shader` (`config/iris.properties`, Forge'da `oculus.properties`), `datapacks_dir` (server.properties `level-name`, güvenli).
- `content_cmds.rs`: `world` = kendi dünya kimliği ya da `join:<id>`. Kayıt klasörü: kendi `instances/<id>/meta`, katılınan `app_data/joined/<id>`; ekstralar `<kayıt>/client-extras/`. Oyun klasörü: modlu dünyada `client::targets(mc, launcher, dir_name(name, key))` (key: kendi id / `join_key`), değilse `.minecraft`. Shader yükleyicisi: Forge → `oculus`, diğerleri `iris` (mods::resolve ile Sodium/Embeddium). Oyun açıkken (`join::client::minecraft_running`) ayar dosyalarına dokunulmaz, `note` döner. Veri paketinde `reload` gönderilir. Zorunlu paket: server.properties `resource-pack`/`resource-pack-sha1`/`require-resource-pack`.
- Ekstralar eşitlemeye: `client_cmds::sync_host_inner` ve `join_cmds::install_client_mods` `content_cmds::extras_for(dir)` ekler, eksikse `client-extras`'tan kopyalar. Katılınan dünyada shader değişince `sync_extras` yalnız ekstraları değiştirir (o dünyanın mevcut managed dosyaları wanted'da kalır).
- M10c mod paketleri: `ContentKind::Modpack` (facet: project_type:modpack + server_side:required|optional + loader kategorileri, sürüm facet'i YOK; dünyadan bağımsız — `content_search`/`content_project` dünya çözmeden döner). `modpack.rs` (saf, testli): `read_index`, `target(deps)` (Forge <1.17, NeoForge 1.20.1, bilinmeyen altyapı → hata; `check_supported`, `loader_of`), `place(f)` → Server/ClientMod/ClientFile/Skip (env + resourcepacks/shaderpacks/options.txt istemcide), `safe_rel_path`, `allowed_url` (cdn.modrinth.com, github.com, raw.githubusercontent.com, gitlab.com; https), `ids_from_url`, `extract_overrides` (overrides → server-overrides/client-overrides sırası; `overrides/mods` içindeki istemci jar'ı `mod_env` ile ayrılır; zip sınırları), `apply_client_tree` (yalnız eksik dosyalar; TLauncher'da yalnız resourcepacks/shaderpacks). `modpack_cmds.rs`: `modpack_plan(projectId, versionId?)` → `PackPlan` (kurulabilir sürümler ≤60, mrpack `cache/modpacks/<vid>.mrpack`'te), `prepare`, `install` (dosyalar önce `cache/modpack-files/<sha1>`, 6 paralel, sha512; sonra yerine; `mods.json` + `content.json` `pack_client`/`modpack`/`pack_pending`), `cover_from_project` (`covers::set_auto_cover`, Auto tür), `apply_client_files` (sync_host_inner çağırır, `pack_client_applied`). `create_instance` `modpack: {projectId, versionId}` alır; altyapı/sürüm paketten. `extras_for` = client_mods + pack_client. Arkadaşa: `manifest::pack_client` (Recommended), `host_decider` File dalı ekstralardan servis eder. Canlı test `live_modpack_install`.
- Arayüz: `DiscoverTab = ContentKind`; `kindsFor(loader, own)` sekme kuralları (arkadaşın dünyası: rp (+shader modluysa); kendi saf: rp+dp; Paper: Eklentiler+rp+dp). `useContentActions/usePreview(world, kind)` modlarda `mods_*`, paketlerde `content_*`. Önbellek anahtarı `${world}|${kind}|...`. Kategoriler `format.categoryLabels(kind)`.
