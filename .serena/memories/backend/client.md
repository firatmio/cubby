# backend/client (M7b) — modlar oyuncunun kendi Minecraft'ına

Modlu dünyalar (`LoaderKind::is_modded`: Fabric, Quilt, NeoForge, Forge; Paper eklentileri sunucuda çalışır).
M6: `version_id(kind, mc, lv)` (fabric-loader-…, quilt-loader-…, neoforge-<v>, <mc>-forge-<v>); Fabric/Quilt `ensure_meta_version` (meta profile/json); NeoForge/Forge `install_forge_client` (installer `--install-client` / `--installClient <.minecraft>`, `launcher_profiles.json` yoksa oluşturulur, installer'ın eklediği profil geri alınır, iş klasörü `app_data/cache/installer-*`). `client_cmds::ensure_client_version` Java'yı `JavaManager` ile bulur/indirir. `mod_env` = fabric.mod.json / quilt.mod.json (`dedicated_server`); `need_for(.., strict)`: NeoForge/Forge'da bilinmeyen mod Required. Katılımcıda installer çalışırken `join://progress` index 0 (UI: "NeoForge kuruluyor; birkaç dakika…"). Canlı: `live_neoforge_client`.

- `client/mod.rs` — `detect_launcher(mc)` → Official (`launcher_settings.json`/`launcher_accounts*`) | TLauncher (`TlauncherProfiles.json`/`.tlauncher`) | None. `ensure_fabric_version` (meta.fabricmc.net `/v2/versions/loader/<mc>/<lv>/profile/json` → `versions/<id>/<id>.json`; Launcher kütüphaneleri kendisi indirir). `upsert_profile`/`remove_profile` (`launcher_profiles.json`, serde_json Value ile bilinmeyen alan korunur, `.mcsm-bak` yedek, atomik). `prepare_game_dir` (ilkinde ana `options.txt` kopyalanır). `fabric_env(jar)` (`fabric.mod.json` environment). Kayıt `<mods>/.mcsm.json` (bizim koyduklarımız). `plan()` → Ops (ekle/kaldır/devre dışı/etkinleştir/blocked: kullanıcının aynı adlı dosyası). `sync(mods, world, wanted, shared, fetch)` sha1 doğrular; fetch imzası `FnMut(Wanted, PathBuf) -> Fut` (async closure Send sorunu yüzünden). `targets()`: Official → `.minecraft/mcsm/<slug-id8>/mods` + profil; TLauncher → ortak `.minecraft/mods`, başka dünyanın modları `_disabled/`'a.
- `client/manifest.rs` — `Need {Required, Recommended}`, `ClientMod {file,title,sha1,sha512,size,projectId,versionId,need}`; ModRecord.need (Modrinth `environment`) ya da jar environment'ından; server-only atlanır. `rev()` = manifest hash'i.
- `client_cmds.rs` — `ClientStatus {state off|working|ok|error, launcher, pick, mods, blocked, message}` → event `client://status`; profil anahtarı `mcsm-<id>`, adı `"<Dünya> · MC Sunucu"`, ikon server-icon data URI ya da Furnace. `sync_host` (ayar `client_sync` açıksa + Fabric; SYNC mutex), `spawn_sync` mods_cmds işlemleri / create_instance / sunucu "starting" sonrası. Komutlar `client_status`, `client_resync`. Host profilinin `servers.dat`'ına kendi dünyası localhost olarak.
- Katılımcı (`join_cmds.rs`): protokol `StreamKind::Manifest` (JSON, MAX_BODY 1 MB) ve `File{file}` (yalnız manifest'teki güvenli adlar); ping `Reply::Ok.modsRev`. `preview_invite` → `mods {launcher, required, recommended}` / `modsError`. `install_client_mods`: Modrinth version_id + sha512 eşleşmesi, yoksa p2p; `join://progress`. `join_world(code, force, installRecommended)`; `update_joined_mods`; `remove_joined` profili/ortak modları da temizler. JoinedWorld: `profile, gameDir, modsRev, withRecommended`.
- `settings.rs` — `client_sync` (vars. true), `screenshot_dirs()` (ana + `mcsm/*/screenshots`) → covers/media.
- Canlı: `live_fabric_profile_json`, `live_p2p_pipe` (manifest + dosya).
