# backend/p2p_join (M7a) — uygulamalar arası doğrudan bağlantı + Katıl modu

- `p2p/mod.rs` — `P2p` (Arc, managed): iroh 1.3 `Endpoint::builder(presets::N0).secret_key(..).alpns([ALPN]).bind()`. Anahtar `app_data/iroh.key` (32 bayt, kalıcı → davet linkleri geçerli kalır). Host: `serve(Decide)` — her bi-stream `StreamHeader {world, token, kind: ping|tcp}` JSON satırıyla başlar, `Reply {status: ok|denied|offline}`; tcp+ok → `127.0.0.1:<port>` `copy_bidirectional(join(recv, send), tcp)`. Katılımcı: `connection()` önbelleği (close_reason ile tazelenir), `ping`, `pipe_tcp`. `PathKind` = seçili path `is_relay()`. Aracı: n0 ücretsiz relay'leri (hobi/geliştirme; büyürse kendi iroh-relay).
- `p2p/protocol.rs` — ALPN `b"mcsm/mc/1"`, `MAX_LINE` 1024, bayt bayt `read_line` (başlıktan sonraki veriyi tüketmez).
- `invite.rs` — `Invite {v:1, name, host(EndpointId str), world, token(32 hex), loader, mcVersion, loaderVersion}` → JSON → base64url (no pad). `parse` link (`mcsm://join?d=`) ya da düz kod; boşlukları atar; v≠1 → "güncelleyin" mesajı; alan doğrulama (world=validate_id, sürümler güvenli karakter). `new_token()` = uuid simple.
- `join/mod.rs` — `JoinManager` (Arc): `app_data/joined.json` `JoinedWorld {id, name, host, world, token, loader, mcVersion, loaderVersion, localPort(25600–25999), addedAt}`. Her dünya için `127.0.0.1:localPort` dinleyici → `pipe_tcp`. 20 sn'de bir ping → `join://status {id, status: JoinStatus{reachable, running, path, error}}`. `any_now()` (try_lock) tray kararı için.
- `join/servers_dat.rs` — fastnbt `Value` ile `.minecraft/servers.dat` (bilinmeyen alanlar korunur); upsert en başa, `servers.dat_old` yedeği, atomik yazım. `join/client.rs` — `minecraft_running()` (sysinfo, java + `net.minecraft.client`/`--gameDir`), `required_version` (fabric → `fabric-loader-<lv>-<mc>`), `version_installed` (`versions/<v>/<v>.json`).
- `join_cmds.rs` — `host_decider` (instance.invite_token eşleşmeli; running değilse tcp → offline), `create_invite`/`reset_invite`, `preview_invite` (ping + kontroller, own), `join_world(code, force)` (Minecraft açıksa hata), `list_joined`, `remove_joined` (servers.dat kaydını da siler), `readd_server_entry`, `server_entry_exists`, `refresh_joined`, `take_pending_invite`.
- `lib.rs` — deep-link plugin (`tauri.conf.json` plugins.deep-link.desktop.schemes ["mcsm"], `register_all()` HKCU'ya dev exe'yi yazar), single-instance `deep-link` özelliği, `handle_invite_urls` → `PendingInvite` + `join://invite`. Tray (`tray-icon`): "Aç" / "Tamamen kapat"(begin_shutdown). CloseRequested: sunucu çalışıyorsa ya da katılınan dünya varsa `hide()`; begin_shutdown sonunda `P2p::close()`.
- Canlı test: `cargo test --lib -- --ignored live_p2p_pipe --nocapture` (aynı makinede iki endpoint, yol "Direct").
- M7b: manifest/file akışları, mods_rev, mod kurulumu → `mem:backend/client`.
- Kısa kodlar + web katılım sayfası (2026-10-17): `web/` (Vercel proje `cubby-join`, bölge fra1, çatısız Functions + Upstash Redis free, `KV_REST_API_*`), adres `consts::JOIN_WEB = https://cubby.quacomes.com` (Cloudflare DNS only olmalı; proxy IP sınırını bozar). API: POST /api/invites {invite}→{code,owner}, GET/PUT/DELETE /api/invites/:code (vercel.json rewrite → api/invite?code=), sayfa /:code → api/page (OG, tr/en, CSP, no-store). Kod alfabesi `23456789ABCDEFGHJKMNPQRSTUVWXYZ` × 6, `inv:<KOD>` TTL 60 gün, owner SHA-256. Hız: lookup 30/dk+300/gün (sayfa+API ortak), create 20/saat. Rust `short_invite.rs`: `normalize` (KOD, tire/küçük harf, web linki, şemasız link, `cubby://join?c=`), create/refresh(403|404→false)/delete/resolve, 6 sn timeout. `Instance.short_invite {code, owner, token}`. `join_cmds`: `InviteLinks {code, link, short, web}`, `invite_for` async (kayıtlı kod geçerliyse spawn_refresh, yoksa create; reset'te eski silinir), `invite_from` (kısa kod → resolve → Invite::parse) preview/join'de, `install_refresh` (server running → tazele), olay `invite://short`. Canlı test `live_short_invite_roundtrip`; web testleri `cd web && bun test`.
