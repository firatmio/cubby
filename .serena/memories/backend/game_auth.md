# backend/game_auth (M9) — oyunu Launcher'sız açma + Microsoft girişi

- `consts::MS_CLIENT_ID = option_env!("MCSM_MS_CLIENT_ID")` (Azure public client). Yoksa giriş kapalı, Launcher'lı akış. Mojang onayı yoksa `login_with_xbox` 403 → `xbox::NOT_APPROVED`. Rehber: docs/MICROSOFT_GIRIS.md.
- `auth/oauth.rs` — `consumers` kiracısı, kapsam `XboxLive.signin offline_access`, PKCE (iki UUIDv4 = 64 hex doğrulayıcı), `127.0.0.1:0` dinleyici, redirect `http://localhost:<port>`, `parse_callback` (state kontrolü), `exchange_code`/`refresh` (`invalid_grant` → yeniden giriş). reqwest `form` özelliği.
- `auth/xbox.rs` — XBL (`RpsTicket d=`), XSTS (`rp://api.minecraftservices.com/`, 401 `XErr` → `xerr_message`), `minecraft_login`, `owns_game` (entitlements `game_minecraft`/`product_minecraft`), `profile`.
- `auth/mod.rs` — `AuthManager` (managed): yenileme token'ı `keyring` 3.6 (`mc-server-launcher`/`microsoft-refresh-token`), `app_data/account.json` {name, uuid, skin}; `session()` 24 saatlik token'ı 10 dk payla yeniler. (keyring 4.x API'si değişti, 3.6 bilinçli.)
- `game/mod.rs` — `load_chain` (versions/<id>.json, inheritsFrom, eksik vanilla Mojang'dan sha1'li `Loaders::version_json`), `merge` (kütüphaneler üstten alta, `group:artifact[:classifier]` tekil; args alttan üste; mainClass üstteki; downloads.client olan sürümün jar'ı), `rules_allow` (features hep kapalı), `maven_path`, `missing_files` (var+boyut tutuyorsa atla), `classpath` (url'siz = installer üretmiş, var olmalı). `game/assets.rs` index + objects. `game/launch.rs` `fill`/`command_args` (`${...}`), `masked` (token gizli), `extract_natives`, `windowless_java` (javaw).
- `game_cmds.rs` — `account_status/login/logout`, `open_game_log`, `game_running`; `direct_available` (kimlik + hesap + quickplay 1.20+); `prepare` (dosyalar 16 paralel `game://progress` files/java/starting, Java `JavaManager`, RAM toplamın 1/4'ü 2–6 GB); `start` (std Command, log `app_data/logs/game-latest.log`, `GameState` pid, `game://state` running/exited+code).
- Bağlantı: `client_cmds::start_or_fallback` + `prepare_direct(dir, game_dir)`; `join_after_start` (dosyalar sunucu açılırken) ve `join_cmds::play_joined`. Doğrudan açılamazsa Launcher'a düşer, `LaunchResult.note`. `LaunchResult.game` = doğrudan açıldı.
- Canlı: `live_missing_files_plan`, `live_launch_game` (oyun penceresi açar; `MCSM_LAUNCH_IDS=26.3,neoforge-26.3.0.76`; vanilla ve NeoForge 26.3 ana menüye geldi).
- TLauncher/hesapsız oyuncu için doğrudan açma YOK (Mojang kuralları); onlar Launcher'lı akışta.
